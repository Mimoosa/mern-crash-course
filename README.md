## Overview
This project is a full‑stack MERN application built by following a MERN stack tutorial.
It includes a React (Vite) frontend, an Express + MongoDB backend, REST API functionality, and a production deployment on Render.

## Teck Srack
- React (Vite) – frontend UI
- Zustand – lightweight global state management
- Chakra UI – component styling
- Express + Node.js – backend API
- MongoDB – database
- JavaScript – full‑stack implementation
- Render – production hosting and deployment
